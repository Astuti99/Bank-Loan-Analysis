# 🏦 Bank Loan Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing bank loan data using SQL queries to extract meaningful business insights related to customer credit scores, loan approvals, default rates, income analysis, and repayment behavior.

The project demonstrates SQL skills including:
- Aggregate Functions
- CASE Statements
- GROUP BY
- Subqueries
- Filtering & Sorting
- Business Problem Solving

---

# 🎯 Objectives
- Analyze customer credit score trends
- Identify factors affecting loan approvals
- Track loan default behavior
- Compare EMI burden with customer income
- Study repayment and delayed payment patterns

---

# 🛠 Tools & Technologies
- SQL Server
- SQL Queries
- Relational Database Management System (RDBMS)

---

# 📂 Dataset Information
The dataset contains:
- Customer Details
- Credit Scores
- Loan Amounts
- EMI Information
- Employment Status
- Loan Status
- Delayed Payments
- Default Information

---

# 📊 Business Problems Solved

### ✅ Credit Score Analysis by Age Group
Used CASE statements and aggregation functions to analyze average credit scores across different age categories.

### ✅ Education Level & Loan Approval
Analyzed how customer education level impacts loan approval rates.

### ✅ Highest Approved Loan Amounts
Identified customers with the highest approved loan amounts.

### ✅ Delayed Payments vs Credit Score
Studied whether lower credit scores lead to higher delayed payments.

### ✅ EMI Burden Analysis
Compared monthly installment amounts with customer monthly income.

### ✅ Loan Term vs Default Rate
Analyzed how longer loan terms influence default rates.

### ✅ Gender-Based Default Analysis
Compared loan default rates between male and female customers.

### ✅ Loan Type Repayment Burden
Identified loan types with the highest average monthly installment.

### ✅ Employment Status vs Default Rate
Analyzed how employment status affects loan default percentages.
