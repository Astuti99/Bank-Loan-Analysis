#  Bank Loan Analysis Using SQL

##  Project Overview
This project focuses on analyzing bank loan data using SQL queries to extract meaningful business insights related to customer credit scores, loan approvals, default rates, income analysis, and repayment behavior.

---

#  Objectives
- Analyze customer credit score trends
- Identify factors affecting loan approvals
- Track loan default behavior
- Compare EMI burden with customer income
- Study repayment and delayed payment patterns

---

#   Conclusion
This project provides valuable insights into customer loan behavior, credit performance, repayment trends, and default risks using SQL analysis techniques.
